# Autonomous Code Agent

A beginner-level project to learn AI coding agents by building a system that understands tasks, generates code, executes programs, and identifies errors.

## Goals

- Learn AI agents and Large Language Models (LLMs).
- Understand agentic workflows and tool calling.
- Explore automated code generation and debugging.
- Learn secure, sandboxed code execution.
- Understand backend development and API integration.
- Practise Python programming and AI engineering.

## Technologies

- Python
- FastAPI
- LLM APIs
- Linux
- Docker
- Git
